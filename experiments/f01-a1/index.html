Sprite Renderer

Turn any 3D model (.glb, .gltf or .fbx) into one game-ready sprite sheet: a resting frame, animation frames from one or many clips, an optional spin strip and optional tilted frames, all cropped to the same box. What you see in the dashed square is what gets rendered. Everything runs in your browser; nothing is uploaded.

Choose Model File

A single .glb or .fbx file (Mixamo downloads work), or scene.gltf + scene.bin together (plus any texture files)
